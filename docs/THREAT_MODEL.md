# Threat model

Kept current with every PR: a PR that adds or changes a mitigation updates its row. One owner per row is
the component that carries the mitigation. Status: **planned** (not built), **built** (code + test), or
**verified** (shown on testnet).

Trust assumptions, stated plainly: OutLayer and Intel TDX attestation are trusted to run only the pinned
wasm and keep its env private; NEAR consensus is trusted for lease state; the owner's browser is trusted at
the moment a key is pasted. KeyLease is a hackathon prototype, not audited.
